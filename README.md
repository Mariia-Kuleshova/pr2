# Painting Courses Web App

React SPA проєкт з маршрутизацією, Redux Toolkit та аналітикою.

## Основні можливості

- React Router (динамічні маршрути)
- Форма реєстрації з Zod validation
- Redux Toolkit Store
- Async Thunks
- Entity Adapter
- Динамічна фільтрація учасників
- Аналітика через Recharts
- Адаптивний дизайн

## Analytics

Сторінка Analytics відображає графік активності реєстрацій на основі даних API.
